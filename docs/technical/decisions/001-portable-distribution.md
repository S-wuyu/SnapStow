# 001 · Windows 便携发布与数据位置

**状态**：已确认 · 2026-11-21

## 决定

发布可解压的 Windows 便携目录，用户双击主程序运行。包内可包含 OCR 模型和所需运行库。应用运行数据以主程序所在目录为根，包括截图、数据库、设置、缓存和日志。归档附件与项目资料文档写入用户独立选择的工作总目录。产品行为见 [PRD §4.5](../../../PRD.md#45-便携运行与数据位置)。

## 取舍

- 便携目录可把程序、模型和应用状态一起搬移。工作总目录独立配置，应用可直接使用用户已有的项目目录，材料按用户原有的整理和备份方式管理。
- 单个 EXE 可以减少可见文件，但不必把模型、原生库和程序封成一个文件。选择封装方式时以干净 Windows 上的双击可用、资源加载和本地写入位置实测为准。
- 软件目录必须可写。应用状态路径按主程序定位，工作总目录以独立路径配置。两处写入分别核验真实目标，防止目录联接或符号链接使写入离开对应存储根。
- 同机只搬动软件目录时，应用沿用保存的工作总目录路径。截图保护方式仍需定型。现有 DPAPI 建议通常绑定 Windows 用户和机器，跨机器或换账号迁移凭据截图时需要单独决定保护与迁移方案。[Windows DPAPI](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)

## 验证

用正式结构的发布包在本机测试目录验证双击启动、两个存储位置、目录不可写、只搬软件目录后仍能访问项目与旧版升级。干净系统的依赖覆盖单独记录。目录命名、升级步骤和签名策略待实现或原型确认。[Windows 发布与测试方案](../windows-testing.md)
